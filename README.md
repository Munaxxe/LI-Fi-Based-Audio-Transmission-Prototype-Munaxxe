## ABOUT THE PROJECT

The **Li-Fi Based Audio + Text Transmission Prototype** explores the use of visible light communication (VLC) to transmit audio/text signals wirelessly.

Unlike conventional wireless communication technologies that rely on radio frequency signals, Li-Fi uses modulated light to transfer information between a transmitter and a receiver.

This prototype demonstrates the fundamental concept of transmitting audio through light, providing a practical exploration of optical wireless communication.

## HOW IT WORKS

The system operates through two main stages:

<table>
<tr>
<td width="50%" valign="top">

### 01 / TRANSMITTER

The audio and text signal is used to modulate a light source, allowing information to be transmitted through variations in light intensity.

</td>
<td width="50%" valign="top">

### 02 / RECEIVER

A light-sensitive receiver detects the transmitted optical signal and converts it back into an electrical audio and text signal.

</td>
</tr>
</table>

<p align="center">
  <strong style="color:#89CFF0;">AUDIO SIGNAL + TEXT → LIGHT TRANSMISSION → AUDIO RECEPTION + TEXT</strong>
</p>
